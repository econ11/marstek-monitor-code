  1. Стовпчики — жовті (жовтий = без світла). День, частину якого відновлено з хмари, заштрихований; день, коли станція вимкнулась, має червону крапку над стовпчиком. Над стовпчиком — значення, щоб не наводити мишу заради цифри.
  2. Клік по стовпчику залишає в таблиці лише відключення того дня (інші рядки ховаються), у шапці таблиці з'являється чип «чт 19.11 ×». Стовпчики фокусуються з клавіатури, Enter/Space = клік.
  3. Шкала годин завжди з нуля, крок 2 год; верх — найближче парне над максимумом. Для періодів > 30 днів — стовпчики по тижнях, шкала «годин на тиждень».
  4. Таблиця: «сьогодні»/«вчора» замість дати для двох останніх днів; рядок, що триває, має пігулку замість кінця. Довгий текст примітки переноситься — рядок росте, нічого не обрізається.
