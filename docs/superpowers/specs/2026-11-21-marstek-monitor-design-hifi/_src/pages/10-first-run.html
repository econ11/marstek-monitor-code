Як увімкнути локальний API

Локальний API вмикається на самій станції — через застосунок Marstek Venus Monitor (по Bluetooth) або через підтримку Marstek. Покрокова інструкція — у README проєкту.

  1. Станція і цей комп'ютер мають бути в одній мережі Wi-Fi.
  2. Якщо Windows запитає дозвіл для Marstek Monitor, дозвольте доступ у приватних мережах.
  3. Після ввімкнення натисніть «Шукати знову» — тут же, нікуди не переходячи.

Перейти до огляду
  1. Одна сторінка, не майстер. Плитки способів завжди вгорі; під ними змінюється тільки область результату. Повернутись з будь-якого стану — клік по іншій плитці.
  2. NONE_FOUND: рівно три дії + текстове «Шукати знову». Головна — хмара (працює без налаштування станції). Якщо додаток сам визначив причину (профіль мережі, брандмауер, немає LAN) — блок діагнозу з синьою іконкою над діями, замість загальної поради.
  3. CLOUD_INCOMPATIBLE — помилка в червоній плашці під формою (не модальна), з кодом для звіту; пароль очищено, пошта лишається. Ніякої вини користувача в тексті.
  4. DONE: назва редагується на місці (≤ 24 символи — бюджет трею), пропозиція хмари — одна картка, закривається назавжди. Перемикачі автозапуску й трею видно тут, бо далі вікно «зникне» в трей.
  5. Рядки — з каталогу §13.1 (onboarding.none.*, onboarding.dx.*, onboarding.lanGuide.*, onboarding.cloud.*, onboarding.done.*).
