Marstek Monitor — hi-fi

Нічний прилад, а не дашборд. Синьо-графітова темрява, один рівний ритм кілець, кольори, що мають рівно одне значення кожен. Усе розраховано на погляд із-за плеча під час блекауту: «є світло чи ні, скільки лишилось, коли вимкнеться».

Кільце — анатомія

  • Коробка 120 × 120 px, viewBox 0 0 120 120, r = 50, штрих 10 → зовнішній діаметр 110, внутрішній 90.
  • Трек --color-track, заповнення — колір тону, stroke-linecap: round, старт о 12-й, за годинниковою (rotate −90°), pathLength="100" → dasharray = відсоток.
  • 0% — заповнення не малюється взагалі (інакше круглий кінець дає крапку). 100% — повне коло.
  • Заголовок над кільцем: 12 px caps, muted. Значення в центрі: 28/600 (23 px для 4 цифр з одиницею), одиниця 15/500 muted; для часу — підпис «год : хв» 11 px під числом.
  • Під кільцем два рядки: основний 13/500 (може мати колір тону: «розряд»), другорядний 12 subtle.
  • Стани: тон good / warn / info / bad; .gauge--stale — заповнення і число сірі. Зміна значення — 600 мс ease-standard, без анімації при reduced-motion.
